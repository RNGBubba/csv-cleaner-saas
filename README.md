# DataCleanup Pro — Instant CSV & Excel Cleanup

Free online tool to clean messy CSV and Excel files. Remove duplicates, fix formatting, standardize dates, phones, and addresses.

**Try it live:** https://rngbubba.github.io/mr-bubba-csv-cleaner/

## Features

- Remove duplicate rows
- Trim whitespace from all cells
- Standardize dates to ISO 8601 format
- Format phone numbers consistently
- Fix casing in name fields
- Standardize address abbreviations
- Preview changes before downloading

## Usage

1. Upload a CSV or Excel file
2. Python (running in your browser via Pyodide) processes it
3. Download the cleaned CSV
